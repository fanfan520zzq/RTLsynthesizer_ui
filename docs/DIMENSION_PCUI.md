# 外部 Dimension PC 客户端

本仓库仅提供 PC 客户端。音乐合成、音效、SD 播放和后端位流由用户在本仓库外维护；`60k_ui_prj` 是 UI/EC11 示例，不能作为该串口客户端的业务后端。

启动 `verilogQT/启动.bat` 菜单 3，选择兼容外部设备的 COM。协议为 115200 8N1 ASCII；具体命令见 [UART_COMMANDS](../UART_COMMANDS.md)。连接自动查询 `Q` 和 `!Q`。
基础操作为 M/A/P/S/Q 和音色 0..6；四个效果目标参数用 0..255 输入，PC 编码为 HEX，设置 ACK 后再查询核对。
带多文件扩展的外部设备支持 `@L` 扫描和 `@SHH` 加载；没有扩展的设备不能使用这些操作。
一次一个在途请求，普通请求 3 秒、扫描/加载 35 秒超时后断开，不自动重发。异步加载通知不代替所选文件的加载完成回复。
`Q` 只查询 M/A，现有客户端不推断连续播放进度、声部数或当前音色；播放按钮的 ACK 只表示请求接受。
PCUI 二进制回环是另一协议，不能与本 ASCII 客户端混用。

这里的控件和命令不包含音频计算逻辑；需要实际音乐功能时，请连接你另外维护的设备。
